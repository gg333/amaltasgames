# Amaltas Games

The studio's website, served by GitHub Pages: a home page, and for Juni and the Sleeping Giants:

- `juni/` (index.html): the game's page, the Marketing URL for the App Store. Its pictures are in `juni/images/`, made from the game repo's `store/` graphics (screenshots scaled to 1280 x 720 JPEGs).
- `juni/support.html`: help and contact details, the Support URL for the App Store and Google Play.
- `juni/privacy.html`: the privacy policy, the Privacy Policy URL for both stores.
